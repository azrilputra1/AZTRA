AZTRA — Website Starter
========================
Files:
- index.html: halaman website dan konten Bahasa Indonesia
- style.css: desain premium dark, responsif untuk HP dan desktop
- script.js: menu mobile, switch bahasa Indonesia/Inggris, form WhatsApp

Cara menjalankan di MacBook:
1. Extract file ZIP.
2. Buka folder aztra_website di VS Code.
3. Buka index.html di browser, atau gunakan extension Live Server.
4. Klik pilihan bahasa LANG di navigasi untuk berganti Indonesia / English.
5. Uji formulir: isi data lalu tekan tombol WhatsApp. Form akan membuka WhatsApp dengan pesan yang telah disiapkan, tidak menyimpan data ke server.

Catatan:
- Harga paket adalah saran harga awal, bukan penawaran final.
- Contoh portofolio diberi label konsep latihan, bukan proyek klien.
- Domain/hosting belum termasuk harga.
- Fitur kompleks seperti backend, database, login, dan pembayaran perlu estimasi terpisah.
- Terjemahan tersedia melalui kamus bilingual yang tertanam di script.js; bukan penerjemah otomatis untuk teks bebas.
